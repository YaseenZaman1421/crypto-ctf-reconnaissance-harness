# Crypto-CTF Reconnaissance Harness (CCRH)

CCRH is a planned reconnaissance-first toolkit for cryptography CTF challenges.

This initial repository snapshot contains the open-source projects being evaluated as implementation references and integrations. The tool will eventually inventory challenge files, inspect source code, extract cryptographic parameters, rank likely attacks, and produce evidence-backed reports.

## Reference projects

- CtfCryptoTool
- CTF Kit
- CTF-Crypto-Toolkit
- CyberChef
- RsaCtfTool
- xortool

Reference projects are kept separate while licenses, dependencies, and reusable components are reviewed.
